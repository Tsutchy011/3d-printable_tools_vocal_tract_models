# 3D printable tools for vocal tract models

声道模型を用いた音響教育（音源フィルタ理論のデモンストレーション・実習）のために作成した、
3Dプリンタで印刷可能なモデル一式です。

上智大学 荒井研究室「音響音声学デモンストレーション (Acoustic-Phonetics Demonstrations; APD)」で公開されている
**日本語5母音の声道模型 (VTM-T20)** に対応するリード式音源・ケースの他、
スライド式3音響管・それに対応するリード式音源、リードを切り出すための治具などのアタッチメントを収録しています。

- 出典: 辻慎也, 荒井隆行, 「3Dプリンタを活用した音響教育のための教材作成
  ——言語聴覚士養成コースでの取り組み事例——」, 日本音響学会講演論文集, Sep. 2026.
  
- 関連:

## 1. 動作環境

| 項目 | 本稿で使用したもの |
|---|---|
| 3D CAD | OpenSCAD 2021.01 |
| スライサー | eufyMake Studio 3D (Anker) |
| 3Dプリンタ | AnkerMake M5 (Anker), 造形範囲 235 × 235 × 250 mm |
| 素材 | PLA |

`.scad` を編集すれば寸法を変更できます。編集せずに使う場合は `.stl` をそのまま
スライサーに読み込んでください。

## 3. 印刷のコツ（パーツ別）

### 音響管 `acoustic_tube_ID20mm_170mm.stl`
- **立てて（縦置きで）印刷**します。
- 高さ 170 mmで接地面が細いため**ブリム（brim）を推奨**します。
- 内径は 20.0 mm ではなく **20.3 mm** で設計しています。樹脂の収縮を見込んだ値で、
  出力後の実寸がおよそ 20 mm になります。**内径が小さすぎる場合はこの補正値
  (`hole_compensation`) を大きく**してください。
- 外周の3点リブは反り・たわみ防止用です。

### スライダーとロッド `sliding_three_tube_part.stl`
- スライダーは**立てて**、ロッドは**寝かせて**印刷する配置になっています。
  （この向きならサポート材は不要で、ロッドも折れにくくなります）
- ロッドの穴に差し込むと固定されるように作られていますが、固定されない場合には接着剤などお使いください。
- 管内での動きが悪い場合は `body_outer_dia`（既定 19.6 mm）を 0.1 mm 単位で小さくします。

### リード式音源カプセル
- **プラグを上にして逆さに置いた状態**にしてあり、この向きならサポート材は不要です。
- プラグが固くて入らない／緩い場合は、`.scad` の `plug_outer_diameter`
  （VTM-T20用 9.7 mm）や `plug_tip_diameter` / `plug_root_diameter`
  （3音響管用 19.5 / 19.9 mm）を 0.1 mm 単位で調整してください。

### リード固定パーツ
- `.scad` から出力する場合は **`print_ready_orientation = true`** にしてください
  （サポート不要の向きになります）。
- スリット高は `reed_thickness + slot_vertical_clearance`（既定 0.05 mm）です。
  **シートが入らない場合は `slot_vertical_clearance` を 0.05 → 0.1 に増やして**ください。
- 逆にリードがすぐ抜ける場合はこの値を 0 に近づけます。

> [!NOTE]
> `reed_fixing_part_2mm.stl` と `reed_fixing_part_3mm.stl` は
> **STL内の姿勢が異なります**（前者は Z 方向 35 mm、後者は Y 方向 35 mm）。
> スライサー上で寝ている場合は、サポート不要の向きに回転させてください。

### リード裁断治具 `reed_cutter.stl`
- 長辺 **195 mm** です。造形範囲がこれより小さいプリンタでは、
  `.scad` の `render_target` を `"STRIP_BASE"` / `"STRIP_TOP"` / `"CHOP_BASE"` / `"CHOP_TOP"`
  に切り替えて**個別に印刷**してください。

### ケース類
- ケース本体・蓋はいずれも**天面を下にした状態**でSTL化してあり、サポート材は不要です。
- 蓋がきつい／緩い場合は `.scad` の `clearance_top`（既定 0.6 mm）と
  `clearance_bottom`（既定 −0.1 mm）で調整します。
  **`clearance_bottom` を負の値にしているのが摩擦固定のポイント**です。

> [!WARNING]
> `VTM_T20_case.stl` は **225 × 225 mm** とAnkerMake M5の造形範囲をほぼ使い切ります。
> ベッド上で斜めに印刷されるように配置（スライサーのZ軸にて45˚回転）してください。

## 4. 印刷設定の目安

<!-- TODO: 実際に使用したスライサープロファイルの値に置き換えてください -->

eufyMake Studio 3Dの設定では、デフォルトで問題なく印刷できました。
以下ではその値を共有します:

| 項目 | 目安 | eufyMakeのデフォルト値 | | 備考 |
|---|---|---|
| 積層ピッチ | 0.15〜0.20 mm | 0.20 mm | 特になし |
| 壁（外周）数 | 3〜4 | 3 | 音響管・カプセルは気密性のため多めに |
| インフィル | 20〜30% | 15% | ケース類は 15% 程度でも可 |
| サポート材 | **基本的に不要です** | サポートなし | 各STLはサポート不要の姿勢で保存しています |
| ブリム | 音響管・長尺パーツで推奨 | 接地面積が小さいため |
| ノズル温度 / ベッド温度 | PLA 標準 | ノズル音度は215˚くらいがおすすめです |

## 5. 組み立てと使い方

1. **リードを切り出す** — 大きい方の裁断治具にクリアファイル等のシートを挟み、カッターで幅 10 mmの短冊状に切り出します。
   その後、小さい方の器具により長さ 30 mmになるよう切っていきます。
   切ったリードはリードケースに保管できます。
2. **リード固定パーツにリードを差し込む** — 1. のシート厚に対応するパーツ
   （0.2 mm 用 / 0.3 mm 用）のスリットにリードを差し込みます。
3. **音源カプセルに挿入する** — 固定パーツを音源本体のリード室に押し込みます。
4. **声道模型に接続する** — VTM-T20 なら 10 mm 用、スライド式3音響管なら 20 mm 用の
   本体を使います。
5. **気流を送る** — 呼気、または空気ポンプでカプセル後端から気流を送ると母音が生成されます。

> 音が鳴らないときは、①気流の勢い、②リードの差し込み量と固定具合、
> を確認してください。
